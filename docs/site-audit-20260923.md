# Аудит и очистка TAU CLOUD — 2026-09-23

## Результат

Проведён аудит текущего рабочего дерева, включая незакоммиченные правки пользователя. Сайт не публиковался. Никакие реальные письма не отправлялись. Перед изменениями сохранена копия исходников: `test-results/audit-20260923/source-before.zip`.

Удалены семь подтверждённо неиспользуемых файлов; список, размеры, SHA-256 и основания записаны в [манифесте очистки](cleanup-20260923.json). Удалены старые стили и лишняя разметка. Найдено и исправлено накопление звуковых обработчиков при смене мобильной/десктопной реализации истории.

## Изменения кода

- Удалены 71 правило/анимация облачного финала, 119 подтверждённо неиспользуемых селекторов старых карточек, навигации и формы, а также отдельные правила старой навигации каталога. Динамические классы Lenis и карточек сохранены. Отрицательные селекторы `:not(.cloud-finale)` сохранены для прежней специфичности каскада.
- Убран невидимый `::before` переключателя языка: после перехода к SVG он не рисовал ничего, но продолжал анимироваться. Видимые SVG-рамка и рука, их пульсация и мобильное скрытие сохранены.
- Поля компании и даты запуска, которые раньше создавались и сразу удалялись JavaScript, убраны непосредственно из шаблона; удалена соответствующая операция в `main.js`.
- `initPreviewSound()` теперь возвращает очистку: AbortController удаляет обработчики, аудиоконтекст закрывается. `initMobileStory()` вызывает очистку при смене режима и уходе со страницы. Добавлен регрессионный тест.
- Из манифеста и скрипта оптимизации убрана ссылка на отсутствующий старый логотип и специальная ветка его обработки.
- Добавлен перевод резервного сообщения Vite API «Сервис временно недоступен.».
- Исправлена проверка потока кадров: ожидание результата прокрутки вместо фиксированной задержки; более плавные тестовые шаги; резервная загрузка проверяется на сцене генератора, поскольку первая сцена теперь использует ambient-видео.
- README приведён к текущей реализации: RU/KZ/EN, локальный Manrope, серверная форма, актуальные источники истории и команды проверок.

## Что сохранено и почему

- Исходные кадры, манифесты, ambient-видео и действующие пакеты — рабочие ресурсы сайта.
- `.media-staging/` содержит два архива TAU CLOUD (~646 МиБ), а не посторонние файлы. Они не удалены: содержимое связано с подготовкой медиа, подтверждённого внешнего архива нет.
- Мастер-видео, отклонённые генерации, референсы и материалы QA сохранены по `docs/ARCHIVE.md` для воспроизводимости и истории проекта.
- Утилиты импорта/генерации и исторические проверки относятся к этому сайту; их отсутствие в клиентском бандле не означает, что они являются мусором. Для актуальной регрессии используйте команды из таблицы выше.
- Зависимости и версии не менялись; `node_modules` и действующий dev-сервер не удалялись.

## Ограничения

Сборка по-прежнему предупреждает о `use client` в зависимостях Framer Motion и основном JS-бандле более 500 kB (около 174,5 kB gzip). Это не ошибки сборки; изменение стратегии загрузки зависимостей не включалось в безопасную очистку.

SMTP-доставка, публичное размещение, физические iOS/Android, Safari/Firefox, полная WCAG-проверка и нагрузочные испытания не выполнялись. Локальный `mobile-preview.html` работает; заголовок `X-Frame-Options: DENY` на Netlify может запрещать его iframe на публичном хостинге — конфигурация публикации не менялась. Аудит npm не доказывает отсутствие всех возможных уязвимостей.
