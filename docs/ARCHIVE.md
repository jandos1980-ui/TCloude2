# Архив медиа

Внешнее хранилище для архива ещё не выбрано. До его выбора и проверки загрузки перечисленные ниже файлы нельзя удалять из репозитория.

## Правила передачи

Для каждой передачи зафиксируйте дату, назначение, конечный путь, размер и SHA-256. После этого проверьте скачивание архива и только затем удаляйте локальную копию отдельным коммитом.

## Кандидаты

- Отклонённые видео из `public/media/`: `tau-cloud-energy.mp4`, `tau-cloud-film.mp4`, `tau-cloud-white-clouds.mp4`, `tau-cloud-krea-new.mp4`, `tau-cloud-hero-12s-krea.mp4`.
- Мастер-файлы: `tau-cloud-energy-corrected.mp4` и его портретная версия. Они не нужны сайту, но необходимы для повторной обработки в исходном качестве.
- Результаты генерации и QA: `docs/ambient-results/` и `docs/ambient-refs/` — переносить только вместе с относящимися генеративными скриптами и заметками.

Не архивируйте и не удаляйте без отдельной проверки `public/media/ambient/`, кадры последовательностей или их `manifest.json`: это production-ресурсы.
