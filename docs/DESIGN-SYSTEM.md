# Визуальная система

Снимок текущих правил на 2026-09-23. Источник значений — `src/brand-system.css`; отдельные компоненты и адаптивные стили могут их уточнять. `style-tile.html` — вспомогательный образец, не исчерпывающая спецификация всех состояний.

## Базовые значения

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--brand-accent` | `#49bff0` | Акцент и основные действия |
| `--brand-link` | `#155f80` | Ссылки и подписи на светлом фоне |
| `--brand-ink` | `#17272f` | Заголовки |
| `--brand-copy` | `#405865` | Основной текст |
| `--brand-surface` | `#eaf0f3` | Светлая поверхность |
| `--brand-card` | `#f3f7f9` | Карточки |
| `--brand-line` | `#bfd0d9` | Разделители |

Шрифт — локальный Manrope Variable с резервными Arial/sans-serif. Заголовки разделов: `clamp(32px,3.5vw,54px)`, вес 500; подзаголовки — `clamp(24px,2.3vw,34px)`. Базовый текст — 14 px, подписи — 10 px. Это базовые токены, не требование сделать весь интерфейс одинакового размера.

Вертикальные отступы разделов: `clamp(64px,6vw,96px)`; боковые — `max(6.2%,calc((100vw - 1480px)/2))`, с мобильными уточнениями. Перед добавлением значения проверьте существующий компонент и его стили.

## Компоненты и состояния

- Основные CTA используют голубой акцент, тёмный текст и тонкую рамку. Фокус должен оставаться видимым, действие — доступным с клавиатуры.
- Фотографии площадок заполняют выделенную область; на мобильном используются пропорции 5/3 с сохранением боковых отступов. Тонировка есть у всех видимых фотографий и снимается при hover/active/focus-within, а не просто при попадании карточки в область просмотра.
- Переключатель языка показывает один язык, меняет RU → KZ → EN, имеет прозрачный фон и общий контур рамки/руки. На мобильном контур 24×24 px, область нажатия 44×44 px; при скрытии вместе с логотипом исключается из взаимодействия через `inert`.
- Отраслевые кнопки переносятся в доступной ширине; слова не должны превращаться в вертикальные цепочки слогов.
- Логотип используется в предоставленных цветах. Фотографии/визуализации и статусы площадок должны сохранять достоверный смысл.

## Движение и адаптивность

Учитывайте `prefers-reduced-motion`: пульсация языка отключается, история использует предусмотренный упрощённый режим. Новая анимация не должна блокировать действие или требовать ожидания. Для точных длительностей и кривых проверяйте CSS соответствующего компонента.

Основная граница мобильной истории — 600 px. Проверяйте обе стороны границы, узкие экраны 320/390 px и длинные тексты на всех трёх языках. Общая проверка описана в [TESTING.md](TESTING.md).
