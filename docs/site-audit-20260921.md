# Проверка сайта — 21 сентября 2026

Проверена локальная версия TAU CLOUD. Проверки браузера: Chromium на Windows, масштаб 100%, восемь размеров окна от 320×700 до 1920×1080.

## Исправлено

После успешной отправки заявки выбор новой услуги через CTA не снимал блокировку кнопки отправки: программное изменение select не вызывало input. Теперь выбор услуги уведомляет форму об изменении. Регрессионная проверка воспроизводит успешную отправку, переход к другой услуге и повторную доступность кнопки.

Сценарий `npm run check:visual` обновлён: удалены проверки отсутствующих поля email и скачивания брифа, добавлены текущие сценарии сайта. API формы в браузерных тестах подменяется; письма не отправляются. BASE_URL позволяет указать другой локальный сервер, QA_OUTPUT — каталог результатов (по умолчанию test-results/site-audit).

## Проверенные шаги

1. Главный экран: все шесть сцен, прокрутка вперёд/назад; подсказка остаётся под точками без смещения и исчезновения.
2. Компания: текст, показатели и переход к площадкам; отсутствуют несуществующие внутренние якоря.
3. Услуги: четыре вкладки, клавиатурное переключение и передача выбранной услуги в форму.
4. Отрасли: семь вкладок и соответствующие панели после завершения перехода.
5. Надёжность: фон, три блока и загрузка изображения.
6. Площадки: шесть карточек, три диалога проектов; Escape закрывает диалог и возвращает фокус.
7. Форма: обязательные поля, сохранение данных при ошибке, имитация успеха, защита от повторной отправки, новая заявка после выбора услуги.
8. Футер: четыре иконки, ссылки телефонов и info@taucloud.kz.
9. Адаптивность: 1920×1080, 1366×768, 1280×600, 800×900, 601×700, 600×800, 390×844, 320×700; восемь разделов без горизонтального переполнения. Мобильное меню и шесть сцен работают.
10. Режим уменьшенного движения: desktop canvas скрыт. Страница дизайн-системы открывается.

## Границы проверки

Реальная доставка SMTP и публичный хостинг не проверялись. Для production нужны настроенные SMTP и серверный обработчик /api/contact; обычный статический dist не отправляет письма. Физические iOS/Android, Safari/Firefox, медленная сеть, полная проверка WCAG и нагрузочные испытания не выполнялись. Проверка не подтверждает актуальность коммерческих сведений и мощностей площадок. Отсутствие известных npm-уязвимостей не является полной гарантией безопасности.
