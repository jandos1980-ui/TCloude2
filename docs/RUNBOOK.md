# Обслуживание и диагностика

Сначала зафиксируйте время, URL, коммит/выпуск, ширину окна, язык и шаги воспроизведения. Не записывайте персональные данные заявок или SMTP-реквизиты. Публичное размещение и внешние системы мониторинга пока не подтверждены.

| Симптом | Проверка | Действие |
| --- | --- | --- |
| Локальная страница не открывается | Терминал Vite, адрес и порт | Запустить `npm run dev` из корня; использовать выведенный адрес |
| Сборка останавливается на кадрах | Вывод `prebuild`, исходные кадры и `manifest.json` | Восстановить отсутствующие входы из проверенной копии; не обходить упаковщик удалением манифеста |
| Фото/история пустые | Network: путь, статус и тип ответа | Проверить наличие ресурса в `public/media/` и сборке; HTML вместо медиа указывает на fallback маршрутизации |
| История ломается после изменения ширины | Граница 600 px, ошибки JS | Выполнить тест потока и проверку смены реализации; проверить освобождение обработчиков и звука |
| Язык смешанный | Словарь, динамический текст, `html lang` | Проверить `src/locales/messages.json`, выполнить тест языков; не переводить значения полей пользователя |
| Публичный выпуск сломан | Последний рабочий выпуск и текущие изменения | Выполнить откат по [DEPLOYMENT.md](DEPLOYMENT.md), затем повторить проверки |

## Форма заявки

В DevTools проверьте ответ `/api/contact`, не публикуя тело запроса:

| Код | Значение/следующий шаг |
| --- | --- |
| 200 | SMTP принял письмо; отдельно проверить входящие и спам |
| 400 | Невалидные поля, JSON либо сработало скрытое поле защиты |
| 403 | Источник запроса не совпадает с origin API |
| 405 | Метод не POST; для диагностического GET это ожидаемо |
| 413 / 415 | Превышен размер тела / неверный Content-Type |
| 429 | Проверить ограничение частоты на хостинге; не повторять запросы циклом |
| 502 | Отправка не подтверждена: проверить доступность SMTP и разрешённого отправителя |
| 503 | Проверить наличие и формат серверных SMTP-переменных |
| HTML вместо JSON | Проверить маршрут Functions; `npm run preview` не содержит API |

Обработчик журналирует фиксированные коды, например `contact_delivery_failed`, без содержимого заявки. Настройки SMTP берутся из окружения; локально после их изменения нужен перезапуск Vite. Подробности — [contact-setup.md](contact-setup.md).

При потере ответа письмо могло быть отправлено. Автоматического безопасного повтора с серверной дедупликацией нет: не запускайте повторную отправку вслепую. Проверка реальной доставки требует отдельного поручения.

## Восстановление и хранение

Git хранит исходники, но не заменяет резервную копию игнорируемых файлов. Сохраняйте медиа и манифест архива с размером и SHA-256 согласно [ARCHIVE.md](ARCHIVE.md). Внешнее хранилище ещё не выбрано; локальная копия на том же диске не защищает от его потери.

`npm run clean` удаляет `node_modules`, `dist`, `test-results`; `clean:all` также удаляет `.media-staging`. Эти команды не являются универсальным способом устранения проблем и не должны запускаться автоматически. После инцидента запишите причину, исправление, проверку и оставшиеся ограничения.
