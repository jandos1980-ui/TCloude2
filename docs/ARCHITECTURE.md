# Архитектура TAU CLOUD

Сверено с исходниками 2026-09-23. Сайт на Vite и ES Modules; React используется для отдельных компонентов, а не для всей страницы.

## Инициализация

`index.html` загружает `src/main.js`. `src/content.js` содержит данные услуг и площадок и собирает разметку. `main.js` вставляет её в `#app`, подключает взаимодействия, форму, историю и React-карусель площадок из `src/components/ui/services-card.tsx`.

Дополнительные входы сборки: `style-tile.html` — визуальный образец, `mobile-preview.html` — вспомогательный просмотр. Они объявлены в `vite.config.js`.

| Подсистема | Основные файлы | Ответственность |
| --- | --- | --- |
| Контент | `src/content.js`, `src/story-content.js` | Тексты, характеристики и сцены |
| История | `src/responsive-story.js`, `src/story.js`, `src/mobile-story.js` | Выбор реализации и её жизненный цикл |
| Прокрутка и меню | `src/smooth-scroll.js`, `src/mobile-nav.js` | Lenis, навигация, фокус |
| Площадки | `src/components/ui/services-card.tsx` | Embla-карусель, галереи, переход к заявке |
| Отрасли | `src/industries.js` | Выбор отрасли и связь с услугой |
| Локализация | `src/i18n.js`, `src/i18n-core.js`, `src/locales/messages.json` | RU/KZ/EN, динамические тексты, сохранение языка |
| Форма | `src/brief.js`, `server/contact.mjs` | Клиентские состояния и серверная проверка/SMTP |
| Медиа | `src/images.js`, `src/image-manifest.json`, `scripts/pack-sequence.mjs` | Подбор изображений и упаковка кадров |

## Адаптивность и ресурсы

При ширине до 600 px включительно используется мобильная история; выше — десктопная. `responsive-story.js` вызывает очистку предыдущей реализации при смене границы и при `pagehide`, восстанавливает её после возврата из bfcache. Неактивная история получает `inert`. Обработчики, таймеры и аудиоконтексты должны освобождаться вместе с реализацией.

`predev` и `prebuild` упаковывают кадры в бинарные потоки и создают `playback.json`. Поэтому исходные кадры и манифесты являются входами сборки. При недоступности потока предусмотрена загрузка отдельных кадров. Правила сохранности — в [ARCHIVE.md](ARCHIVE.md).

CSS подключается из `main.js` и компонентов. Порядок импортов и специфичность важны: `brand-system.css` и специализированные файлы уточняют базовые стили. Не удаляйте правило только потому, что его селектор отсутствует в первоначальном HTML: часть классов и состояний создаётся динамически.

## Состояние и данные

Выбор языка сохраняется в `localStorage` под ключом `tau-language`; KZ соответствует `html lang="kk"`. Пользовательские значения формы не переводятся. Значения услуг для API остаются стабильными независимо от языка. Подробности — [localization.md](localization.md).

Форма отправляет JSON в `POST /api/contact`. В dev запрос принимает плагин Vite, на Netlify — адаптер `netlify/functions/contact.mjs`; оба используют `server/contact.mjs`. Обработчик проверяет источник, тип и размер тела, поля и допустимую услугу, затем отправляет текстовое письмо фиксированному получателю. Базы данных заявок в проекте нет. Успех означает принятие письма SMTP-сервером.

`npm run preview` не подключает API. Одна статическая папка `dist/` не обеспечивает отправку заявок. Настройка описана в [DEPLOYMENT.md](DEPLOYMENT.md) и [contact-setup.md](contact-setup.md).
