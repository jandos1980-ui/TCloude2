# TAU CLOUD

Русскоязычный сайт дата-центра с кинематографичной историей, услугами, площадками и локальным брифом проекта.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
npm run build
npm run preview
```

Локальный адрес: http://127.0.0.1:5173. Готовая сборка: `dist/`. Публичная публикация не выполнялась.

## Редактирование

- `src/content.js` — главы истории, услуги, характеристики площадок.
- `src/main.js` — остальные тексты и структура страницы, форма, управление прокруткой.
- `src/style.css` — цвета, типографика, адаптивная вёрстка.
- `style-tile.html` — отдельный редактируемый образец дизайн-системы.
- `public/media/` — исходные фотографии и логотипы. `logo.png` и `brand-master.jpeg` сохранены из предоставленных файлов. В шапке исходный монохромный логотип отображается белым через CSS-фильтр.

Форма отправляет заявки на info@taucloud.kz через серверный SMTP-обработчик. Для запуска нужны почтовые реквизиты: см. [настройку приёма заявок](docs/contact-setup.md). Без настройки форма показывает ошибку, а не ложное подтверждение.

Шрифт Manrope подключён через Google Fonts; при отсутствии доступа используется Arial. Для полностью автономного размещения можно добавить локальные WOFF2.

## Медиа и движение

Генерация заказана через Higgsfield: Seedance 2.5, 16 секунд, 720p, 16:9, без аудио. Идентификатор задания и промпт находятся в `docs/generation.json`. Видеопоследовательность загружается по манифесту `public/media/sequence/manifest.json`. Если она недоступна, сайт использует предоставленные фотографии и сохраняет все тексты и действия.

Активная дистанция истории на desktop: 5 высот экрана плюс одна видимая сцена. Mobile: 4 плюс одна видимая сцена. Главы: 23%, 25%, 26%, 26% активной дистанции; первые 13% каждой главы — остановка кадра для чтения. Native scrolling, обратная прокрутка, переходы между главами и пропуск истории. При reduced motion — фотографии без движения камеры. Кэш декодированных кадров ограничен окрестностью ±18 кадров, одновременно не более трёх запросов. Неудачные кадры не запрашиваются бесконечно.

## Источники и ограничения

Факты взяты из предоставленного документа «Tau Cloud — о Компаний для сайта.txt», без независимой проверки. Проектные площадки отделены от готовой; сертификат Tier III не заявляется. Визуальные материалы включают предоставленные пользователем сгенерированные изображения; ролик — художественная визуализация, а не документальная съёмка прохода по объекту.

`node scripts/check.mjs` проверяет взаимодействия в установленном Chrome. Скриншоты сохраняются в `test-results/`.
