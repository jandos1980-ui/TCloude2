# TAU CLOUD

Сайт дата-центра на русском, казахском и английском языках: визуальная история, услуги, площадки и серверная отправка заявки.

Документация: [указатель](docs/README.md), [архитектура](docs/ARCHITECTURE.md), [публикация](docs/DEPLOYMENT.md), [проверки](docs/TESTING.md), [обслуживание](docs/RUNBOOK.md). Для разработки — [CONTRIBUTING.md](CONTRIBUTING.md); история изменений — [CHANGELOG.md](CHANGELOG.md).

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Локальный адрес: http://127.0.0.1:5173. Готовая сборка: `dist/`. Публичная публикация не выполнялась.

## Обслуживание проекта

- `npm run clean` — удаляет воспроизводимые локальные артефакты: `node_modules`, `dist` и `test-results`.
- `npm run clean:all` — делает то же и удаляет `.media-staging`. Используйте только когда нет незавершённого импорта или генерации медиа.
- `npm run typecheck` — проверяет TypeScript/TSX без записи файлов.
- `npm run check:visual` — запускает ручную визуальную регрессионную проверку в локальном Chrome; предварительно нужен запущенный `npm run dev`. Скриншоты записываются в `test-results/`.

Очистка никогда не запускается автоматически при разработке, сборке или тестах. Не удаляйте `public/media/ambient/`, исходные кадры последовательностей и их `manifest.json`: они нужны сайту и/или сборке.

### Архив медиа

Отклонённые генерации, исходные мастер-видео и результаты QA нужно переносить во внешнее хранилище только вместе с манифестом архива. До выбора хранилища не удаляйте такие файлы из репозитория.

## Редактирование

- `src/content.js` — HTML-разметка, услуги и характеристики площадок.
- `src/story-content.js` — тексты глав истории.
- `src/locales/messages.json` — переводы KZ/EN; см. [локализацию](docs/localization.md).
- `src/main.js` — инициализация страницы, взаимодействия и связи CTA с формой.
- `src/brief.js`, `server/contact.mjs` — клиентская форма и серверная отправка.
- `src/style.css` — цвета, типографика, адаптивная вёрстка.
- `style-tile.html` — отдельный редактируемый образец дизайн-системы.
- `public/media/` — исходные фотографии и логотипы. `logo-preview-wide.png` — предоставленный цветной логотип с голубым облаком; используется в шапке и подвале без перекрашивания.

Форма отправляет заявки на info@taucloud.kz через серверный SMTP-обработчик. Для запуска нужны почтовые реквизиты: см. [настройку приёма заявок](docs/contact-setup.md). Без настройки форма показывает ошибку, а не ложное подтверждение.

Manrope подключён локально через `@fontsource-variable/manrope`; загрузка Google Fonts не требуется.

## Медиа и движение

Десктопная история использует текущую последовательность `public/media/energy-sequence/`, фотографии и ambient-видео. Мобильная история показывает шесть оптимизированных кадров из `public/media/mobile-stills/optimized/`. Переключение между реализациями происходит на границе 600 px. При уменьшенном движении десктоп использует неподвижное изображение.

`predev` и `prebuild` упаковывают исходные кадры четырёх последовательностей в бинарные потоки и обновляют `playback.json`. Исходные кадры сохраняются для повторной сборки и покадрового резервного режима. При недоступном потоке загрузчик переключается на отдельные кадры.

## Проверки

- `npm test` — обработчик формы, данные площадок, локализация и жизненный цикл звука.
- `npm run check:visual` — история, услуги, отрасли, площадки, форма и восемь размеров экрана в Chrome.
- `node scripts/check-languages.mjs` — RU/KZ/EN, сохранение выбора, динамические тексты и форма.
- `node scripts/check-frame-stream.mjs` — поток кадров, обратная прокрутка и резервная загрузка.

Для браузерных проверок нужен dev-сервер; запросы формы в основных проверках перехватываются, письма не отправляются. Результаты аудита и очистки: [2026-09-23](docs/site-audit-20260923.md).

## Источники и ограничения

Факты взяты из предоставленного документа «Tau Cloud — о Компаний для сайта.txt», без независимой проверки. Проектные площадки отделены от готовой; сертификат Tier III не заявляется. Визуальные материалы включают предоставленные пользователем сгенерированные изображения; ролик — художественная визуализация, а не документальная съёмка прохода по объекту.

`node scripts/check.mjs` проверяет взаимодействия в установленном Chrome. Скриншоты сохраняются в `test-results/`.
